# Personal Finance Management System

**Developer:** Premchandu Chukka  
**Project Type:** Individual Python Project

## Project Overview
A Python command-line application for recording income and expenses, organizing expenses by category, setting a monthly budget, and viewing financial summaries.

## Features
1. Income Entry
2. Expense Recording
3. Expense Categories
4. Monthly Budget
5. Budget Validation
6. Transaction History
7. Category-Wise Expense Summary
8. Savings Calculation
9. Highest Expense Identification
10. Monthly Financial Summary

## Technology Stack
- Python 3
- Python IDLE
- TXT file storage
- Python standard library (`datetime`, `pathlib`)

## Python Concepts
Lists, dictionaries, functions, classes and objects, conditional statements, loops, exception handling, modules, and TXT file handling.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open `main.py` in Python IDLE.
4. Press **F5** or select **Run > Run Module**.

You can also run `python main.py` from a terminal in the project folder.

## Environment Variables
No environment variables are required.

## API and Database Notes
This project does not use an external API or SQL database. Transaction records are saved locally in `transactions.txt`. Monthly budget values are kept in memory and must be entered again after restarting the application.
